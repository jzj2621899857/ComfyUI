# ComfyUI Harness 架构设计规格说明

## 一、为什么需要这个系统

当前 ComfyUI 作为一个强大的生成式 AI 引擎，主要以"个人工具"的形式被使用。然而，要将其提升为工业级的 AI 内容生产系统，需要一套完整的治理与编排机制。Harness Engineering 架构思想通过构建控制器、线束、仪表盘和安全网，实现对 AI 生成过程的标准化控制、调度与反馈。

## 二、系统变更概述

本项目将实现一个完整的 **ComfyUI Harness 三层架构系统**：

- **Harness 控制与编排层**：统一 API 网关、AI 编排器、状态管理器、反馈处理器
- **执行层**：ComfyUI 实例集群管理、模型仓库服务、其他 AI 引擎集成
- **共享数据与反馈层**：提示词/工作流模板库、生成结果与全链路元数据库

### 核心组件

1. **统一 API 网关**
   - RESTful API 端点 `/api/v1/generate`
   - 智能路由与负载均衡
   - 请求验证与认证

2. **AI 编排器**
   - 动态工作流生成与拼装
   - 根据场景自动选择合适的生成策略
   - 支持文生图、图生图、ControlNet 引导等

3. **状态管理器**
   - 任务生命周期追踪（排队、生成中、后处理、失败）
   - Redis 持久化状态存储
   - WebSocket 实时进度推送

4. **反馈处理器**
   - 质量评分分析
   - 错误日志聚合
   - 自动回滚机制

5. **ComfyUI 集群管理器**
   - Docker 容器化部署
   - K8s 集群编排
   - 模型动态挂载

## 四、功能需求

### 4.1 统一 API 网关

#### 场景：接收生成请求
- **当** 客户端发送 POST `/api/v1/generate` 请求时
- **且** 请求包含有效的工作流参数
- **那么** 系统应返回任务 ID 并开始异步处理

#### 场景：查询任务状态
- **当** 客户端发送 GET `/api/v1/task/{task_id}` 请求时
- **那么** 系统应返回当前任务状态、进度百分比、预估剩余时间

#### 场景：取消任务
- **当** 客户端发送 DELETE `/api/v1/task/{task_id}` 请求时
- **那么** 系统应停止该任务的执行并清理相关资源

### 4.2 AI 编排器

#### 场景：文生图流程编排
- **当** 用户请求不包含参考图时
- **那么** 编排器应生成带提示词增强的文生图工作流 JSON

#### 场景：图生图流程编排
- **当** 用户请求包含场景参考图时
- **那么** 编排器应生成带 ControlNet 引导的图生图工作流 JSON

#### 场景：动态 LoRA 选择
- **当** 用户指定了特定风格标签时
- **那么** 编排器应自动组装对应的 LoRA 模型组合

### 4.3 状态管理器

#### 场景：任务状态追踪
- **当** 任务开始执行时
- **那么** 状态应更新为 `processing`，并记录开始时间

#### 场景：WebSocket 进度推送
- **当** 任务执行过程中产生进度更新时
- **那么** 系统应通过 WebSocket 向订阅客户端推送进度

#### 场景：任务完成
- **当** 任务成功完成时
- **那么** 状态应更新为 `completed`，并存储生成结果路径

### 4.4 ComfyUI 执行层

#### 场景：工作流执行
- **当** 编排器下发工作流 JSON 时
- **那么** 执行器应解析并调用 ComfyUI API 执行生成

#### 场景：模型动态加载
- **当** 工作流需要特定模型时
- **那么** 执行器应从模型仓库动态挂载所需模型

### 4.5 反馈处理器

#### 场景：质量评分
- **当** 任务完成后
- **那么** 反馈处理器应对输出结果进行自动化美学评分

#### 场景：异常检测
- **当** 某类任务失败率超过阈值时
- **那么** 系统应触发告警并可选择回滚到旧版工作流

## 五、技术选型

| 组件 | 技术方案 |
|------|----------|
| API 网关 | FastAPI / Kong |
| 状态存储 | Redis |
| 实时通信 | WebSocket |
| 任务队列 | Celery / RQ |
| 模型存储 | S3/MinIO 或 NFS |
| 容器编排 | Kubernetes |
| 工作流引擎 | 自研 + ComfyUI API |
